# VK Bot — интеграция Home Assistant

Кастомная интеграция: настройка через UI, устройство **VK Bot** в разделе
«Устройства и сервисы» со штатным сервисом уведомлений и сенсорами статистики.

## Установка

1. Скопируйте `custom_components/vkbot` в `/config/custom_components/vkbot` на хосте HA
   (должно получиться `/config/custom_components/vkbot/manifest.json`).
2. Перезапустите Home Assistant.
3. Настройки → Устройства и сервисы → «Добавить интеграцию» → **VK Bot**.
4. Укажите URL API аддона (`http://192.168.88.254:8099`) и peer_id получателя по умолчанию.

## Что появится

- **Устройство «VK Bot»** в «Устройства и сервисы»;
- сущность **notify.vkbot** — отправка сообщений получателю по умолчанию;
- сенсоры:
  - «Отправлено всего» / «Отправлено текстов» / «Отправлено фото» / «Отправлено видео» —
    накопленные счётчики аддона;
  - «В очереди» / «Ошибок» — текущий размер очереди по статусам;
  - обновление каждые 30 секунд.

## Использование

Автоматизация:

```yaml
action:
  - action: notify.vkbot
    data:
      title: "Дом"
      message: "Дверь открыта в {{ now().strftime('%H:%M') }}"
```

Смена получателя: измените peer_id в настройках интеграции
(Настройки → Устройства и сервисы → VK Bot → настройка).
